# MaRL Website Project

## Project Description
This website was created to represent the MaRL brand through a clean, modern, and visually engaging web design. The project includes several pages that highlight the brand, product range, reseller opportunities, partnership enquiries, and contact information.

## Styling and Branding
A shared stylesheet was created and applied to every page so that the site maintains a unified look and feel. The design uses the MaRL brand colours, clear typography, and a fresh water-inspired style to reflect cleanliness, purity, and freshness.

## CSS Features Implemented
The CSS design includes:
- a responsive mobile-first layout
- brand-based colour palettes using blue, green, and white tones
- Poppins headings and Open Sans body text
- layered background gradients and bubble-style decorative effects
- glassy section cards with soft shadows and rounded corners
- animated hover effects and subtle uplift on content blocks
- animated header glow and shine effects
- smoother scrolling and floating visual elements
- improved input and button styling to make forms feel interactive and polished

## User Experience Improvements
These CSS enhancements were added to make the website more attractive and easier to use:
- stronger visual hierarchy for easier navigation
- more depth and dimension through shadows, blur, and layering
- smoother transitions to improve perceived quality
- attention-grabbing highlights for key content
- more polished form interactions and clearer focus states

## Pages Included
- `Home.html` – main landing page featuring the brand message and hero section
- `products.html` – product information page
- `resellers.html` – reseller application form
- `partners.html` – partnership inquiry page
- `Contact.html` – contact form page

## Shared Stylesheet
The file `styles.css` contains the complete shared design system, including the brand palette, typography, responsive layout, decorative effects, and animation rules.

## Outcome
The final website presents a more professional, memorable, and visually rich user experience while remaining simple and functional for a school project submission.
